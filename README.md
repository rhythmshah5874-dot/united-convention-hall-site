# United Convention Hall concept site

A responsive, multi-page concept site tailored to United Convention Hall in Chattogram.

Open `index.html` in a browser, or serve this folder locally with any static web server.

Included pages:

- `index.html` — brand story, trust signals, review themes, CTA
- `spaces.html` — venue experience and event settings
- `gallery.html` — filterable image gallery with full-screen lightbox
- `plan-event.html` — interactive enquiry planner and FAQs

The supplied venue photographs are preserved in `assets/` and are used throughout the design.
